# tamagossi.dev

Personal portfolio website for **Raka Pratama** — Lead Frontend Engineer based in Bandung, Indonesia.

**Live:** [tamagossi.dev](https://tamagossi.dev)

## Tech Stack

- **Next.js 16** (App Router, static export)
- **TypeScript** (strict)
- **Tailwind CSS v4**
- **Framer Motion** (scroll animations)
- **Lucide React** (icons)

Design modeled after [Brittany Chiang](https://brittanychiang.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Static export output goes to `out/`.

## Deploy

Deployed via [Vercel](https://vercel.com). Static export with custom domain.
